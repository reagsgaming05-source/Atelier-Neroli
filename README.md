# Atelier-Neroli

## caisse-ecoles

Application locale (fichier HTML autonome) pour remplir automatiquement le journal de caisse
Excel à partir du PDF scanné des pièces comptables. Voir [caisse-ecoles/README.md](caisse-ecoles/README.md).

**Version portable Windows** (application fenêtrée, aucune installation) : `CaisseEcoles-windows.zip`
sur la page *Releases* (« Caisse écoles — Windows portable »), à décompresser puis `CaisseEcoles.exe`.
Deux onglets dans la même fenêtre : **Caisse écoles** (saisie des pièces comptables, pièces
scannées, journal, fichier Excel, PDF des pièces) et **Décompte DGEO** (courses d'école & camps,
embarqué depuis sa propre release).

Fichier HTML seul, prêt à l'emploi : [`caisse-ecoles/dist/Caisse-ecoles.html`](caisse-ecoles/dist/Caisse-ecoles.html)
(télécharger puis double-cliquer).
