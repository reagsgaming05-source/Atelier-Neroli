Les gestes du quotidien

Une feuille à garder près du clavier. Dans l'application, le bouton ? de chaque boîte (ou {{RACCOURCI:raccourcis}}) explique l'outil sans la fermer.

Je veux…Je fais…
Ouvrir un document{{RACCOURCI:ouvrir}}, ou je dépose le fichier dans la fenêtre. Plusieurs fichiers : chacun a son onglet ({{RACCOURCI:nouvel-onglet}}).
Réunir plusieurs PDFOutils › Fusionner des PDF, puis je range les pages dans la vue Organiser ({{RACCOURCI:organiser}}).
Retirer, pivoter, déplacer des pagesVue Organiser : je clique la page, puis {{RACCOURCI:supprimer-pages}} (retirer) ou {{RACCOURCI:pivoter-droite}} (pivoter), ou je la glisse à sa place.
Enlever les pages blanches d'un scanDétecter les pages vides : je contrôle la liste cochée, je supprime.
Corriger une fauteDouble-clic sur la page : l'éditeur s'ouvre, E corrige le texte existant.
Surligner, annoter, tamponnerDans l'éditeur : H surligne, T écrit, P pose un tampon (« Reçu le… »), S signe.
Trouver un mot, un nom{{RACCOURCI:rechercher}} ; {{RACCOURCI:occurrence-suivante}} passe à la suivante.
Caviarder un nom partout{{RACCOURCI:rechercher}}, j'écris le nom, Caviarder tout, je vérifie la liste, j'exporte sous un autre nom, je rouvre la copie pour vérifier.
Rendre un scan cherchableReconnaître le texte : bonnes pages, bonne langue ; quelques secondes par page.
Remplir un formulaireRemplir le formulaire ; pour une série, Remplir en série (CSV).
Alléger un fichier pour un courrielRéduire la taille — le texte n'est plus sélectionnable ; je garde l'original.
Imprimer un livret{{RACCOURCI:imprimer}} › Livret ; recto verso : bords courts.
Enregistrer sans écraser{{RACCOURCI:exporter}} (Enregistrer sous…) crée un nouveau fichier ; {{RACCOURCI:enregistrer}} réécrit celui qui est ouvert.
Défaire{{RACCOURCI:annuler}} (la barre d'état dit quoi) ; {{RACCOURCI:retablir}} rétablit. Ce qui est exporté ne se défait plus.
Chercher un outil{{RACCOURCI:filtre-outils}} : je tape « biffer », « livret », « excel »…

Trois choses à ne pas oublier

  • Rien n'est écrit tant que je n'ai pas enregistré ou exporté. Filigrane, en-tête, mot de passe, aplatissement : réglés maintenant, appliqués à l'export (la ligne sous la barre les liste).
  • Une signature dessinée n'est pas une signature électronique. Pour prouver qu'un document n'a pas changé : Signer avec un certificat.
  • Je verrouille ma session Windows en partant (Windows + L).

Aide-mémoire — verso

Avant d'envoyer, et si ça ne marche pas

Avant d'envoyer un document

  • Je l'ai relu à l'écran tel qu'il partira (vue Lecture), toutes les pages.
  • Caviardage : j'ai rouvert la copie exportée, cherché le nom avec {{RACCOURCI:rechercher}} : zéro résultat. Un mot écrit sans accent ou coupé en fin de ligne m'a échappé ? Je l'ai cherché aussi.
  • Propriétés : le titre est juste ; l'auteur n'est pas quelqu'un qui ne doit pas apparaître.
  • Mot de passe : je l'ai noté ailleurs que sur ce poste, et je le donne par un autre canal que le fichier.
  • Formulaire à renvoyer rempli ? Je décide si je l'aplatis : après l'export, le destinataire ne peut plus rien changer.
  • PDF signé ? Je n'ai rien modifié après la signature (sinon elle est invalide).
  • Gros fichier ? Réduire la taille, ou seulement les pages utiles ; j'ai gardé l'original.
  • Document public (site, mise à l'enquête) ? Vérifier l'accessibilité : titre, langue, balisage.

E-MDPLe document est protégé par un mot de passe.Je le rouvre en donnant le mot de passe.
E-FICHIERLe fichier est vide, coupé ou abîmé.Je le récupère depuis son origine.
E-DISQUEL'écriture est refusée (disque plein, fichier tenu ouvert, droits).Je change de dossier, je ferme le fichier ailleurs.
E-COMPOSANTUne partie du logiciel ne s'est pas lancée.Je ferme et rouvre l'application.
E-POLICEUne police du document pose problème.Je tente une autre police, ou l'export en images.
E-INCONNUCause non identifiée. Rien n'a été écrit.Je recommence ; si ça persiste, rapport de diagnostic.

L'application s'est arrêtée brutalement ? Au lancement suivant, elle propose de reprendre le travail là où il en était.
